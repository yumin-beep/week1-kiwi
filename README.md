# Ruby Kiwi Landing Page

루비 키위를 소개하는 한·영 랜딩 페이지를 만든 웹 실습임.

- 기간: 2026.05.03
- 구분: 개인 웹 제작 실습
- 기술: HTML, CSS, JavaScript

## 만든 내용

- 제품 소개, 특징, 이야기와 문의 구역을 한 페이지로 구성했음.
- 한국어와 영어 페이지를 따로 만들고 서로 이동할 수 있게 했음.
- 화면 크기에 맞춰 배치가 바뀌도록 작성했음.
- 간단한 스크롤 효과와 버튼 동작을 넣었음.

## 실행 방법

- 별도 설치 없이 `index.html`을 브라우저에서 열면 됨.
